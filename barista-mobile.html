호주 카페 주문 훈련 게임

  • 주문이 위쪽에 들어옴 (타이머 주의)
  • 머신에 +컵 사이즈 클릭해서 컵 배치 (머신당 최대 2개)
  • PULL 누르면 그 머신에서 무조건 2샷 추출
  • 샷 완성 후 필요한 재료 추가 (🥛 우유 / 💧 핫워터 / 🍫 초콜릿)
  • ✋ Take로 컵 들고, 주문 카드 클릭해서 서빙
  • 들고 있는 컵을 다시 빈 슬롯에 클릭하면 재료 추가/수정 가능
  • + Keep 컵으로 1샷 따로 받아 보관 → 다른 컵에 ☕+1 로 부어쓰기
  • 틀린 컵·샷·재료 서빙하거나 시간 초과 시 ❤ 잃음
🔑 핵심 — 2샷 분배 규칙
• 한 머신에 컵 1개 두고 PULL → 그 컵에 2샷 (더블)
• 한 머신에 컵 2개 두고 PULL → 1샷씩 분배 (싱글 페어)
• 3샷 만들기: 컵 1개 두고 PULL (2샷) → throwaway 컵 추가 → 다시 PULL (split, +1샷씩) → 타겟 컵 3샷, throwaway 1샷은 버림
